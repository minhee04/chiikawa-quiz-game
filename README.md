# 🐰 치이카와 퀴즈 게임

## 1. 프로젝트 개요

치이카와 캐릭터를 주제로 한 Python 기반 터미널 퀴즈 게임입니다.

사용자는 퀴즈를 직접 추가하거나 삭제할 수 있으며, 등록된 퀴즈를 풀고 자신의 점수와 기록을 확인할 수 있습니다. 퀴즈 데이터와 점수 기록은 JSON 파일에 저장되어 프로그램을 종료한 후에도 유지됩니다.

## 2. 주제 선정 이유

요즘 빠져있는 귀여운 캐릭터들을 활용해 간단하면서 재밌는 퀴즈 게임을 만들고 싶었습니다.

평소 관심 있는 캐릭터를 주제로 선정하여 직접 퀴즈를 만들고 풀어보는 과정을 통해 Python 프로그래밍과 데이터 저장 및 관리 방법을 익히고자 했습니다.

## 3. 개발 환경

| 항목 | 사용 기술 |
|---|---|
| 프로그래밍 언어 | Python 3.13.3 |
| 개발 도구 | Visual Studio Code |
| 데이터 저장 | JSON |
| 버전 관리 | Git, GitHub |

## 4. 주요 기능

### 퀴즈 게임
- 등록된 퀴즈를 무작위 순서로 출제
- 사용자가 원하는 문제 수 선택
- 정답 여부에 따른 점수 계산
- 힌트 기능 제공
- 힌트를 사용한 문제는 정답을 맞혀도 점수 미부여

### 퀴즈 관리
- 새로운 퀴즈 추가
- 등록된 퀴즈 목록 확인
- 퀴즈 삭제

### 점수 관리
- 최고 점수 확인
- 게임별 점수 기록 확인
- 게임 날짜, 전체 문제 수, 정답 수 저장

## 7. 프로그램 구조

본 프로그램은 `Quiz`와 `QuizGame` 두 개의 클래스로 구성되어 있으며, 각각 퀴즈 데이터와 게임 진행을 담당합니다.

### Quiz 클래스

개별 퀴즈 데이터를 관리하는 클래스입니다.

- 퀴즈 ID 관리
- 질문과 선택지 저장
- 정답 및 힌트 저장
- 사용자의 답변이 정답인지 확인

### QuizGame 클래스

전체 퀴즈 게임의 진행과 데이터를 관리하는 클래스입니다.

- JSON 파일에서 퀴즈 데이터 불러오기
- 퀴즈 데이터 저장하기
- 퀴즈 추가 및 삭제
- 퀴즈 목록 출력
- 퀴즈 무작위 출제 및 게임 진행
- 점수 계산 및 최고 점수 관리
- 점수 기록 저장 및 출력
- 메뉴 출력 및 사용자 입력 처리

## 8. 데이터 파일 설명

프로그램의 데이터는 프로젝트 최상위 폴더에 위치한 `state.json` 파일에 저장됩니다.

### 파일 경로

```text
chiikawa-quiz-game/state.json
```

### 파일 역할

프로그램에서 사용하는 퀴즈 정보와 게임 점수 기록을 JSON 형식으로 저장합니다.

프로그램을 종료한 후 다시 실행해도 기존 데이터가 유지됩니다.

### 필드 구조

| 필드명 | 설명 |
|---|---|
| `quizzes` | 등록된 퀴즈 목록 |
| `score_history` | 게임별 점수 기록 |
| `high_score` | 지금까지 달성한 최고 점수 |

**quizzes 필드**

각 퀴즈는 다음 정보를 저장합니다.

| 필드명 | 설명 |
|---|---|
| `id` | 퀴즈 고유 번호 |
| `question` | 퀴즈 질문 |
| `choices` | 객관식 선택지 |
| `answer` | 정답 선택지의 인덱스 |
| `hint` | 퀴즈 힌트 |

**score_history 필드**

각 게임의 결과를 기록합니다.

| 필드명 | 설명 |
|---|---|
| `date` | 게임 진행 날짜 및 시간 |
| `total` | 전체 문제 수 |
| `correct` | 정답 수 |
| `score` | 획득 점수 |

### JSON 데이터 예시

```json
{
  "quizzes": [
    {
      "id": 1,
      "question": "치이카와의 친구 중 파란색을 띠는 캐릭터는?",
      "choices": [
        "하치와레",
        "우사기",
        "모몽가",
        "쿠리만쥬"
      ],
      "answer": 0,
      "hint": "말을 잘하고 기타를 연주하는 캐릭터야."
    }
  ],
  "score_history": [
    {
      "date": "2026-11-01 15:30:00",
      "total": 5,
      "correct": 4,
      "score": 4
    }
  ],
  "high_score": 4
}
```
