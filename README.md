# 치이카와 퀴즈 게임 🐰

Python으로 제작한 터미널 기반 치이카와 퀴즈 게임입니다.

사용자가 퀴즈를 추가하거나 삭제할 수 있으며, 퀴즈를 풀고 점수 기록을 확인할 수 있습니다.

## 개발 환경

- 언어: Python 3.13.3
- 개발 도구: Visual Studio Code
- 버전 관리: Git, GitHub
- 데이터 저장: JSON

## 주요 기능

1. **퀴즈 풀기**
   - 퀴즈를 무작위 순서로 출제
   - 사용자가 풀 문제 수 선택
   - 정답 여부 확인 및 점수 계산

2. **퀴즈 추가하기**
   - 문제와 4개의 선택지 입력
   - 정답과 힌트 설정
   - 추가한 문제를 JSON 파일에 저장

3. **퀴즈 목록 보기**
   - 등록된 퀴즈 확인

4. **퀴즈 삭제하기**
   - 퀴즈 번호로 문제 삭제
   - 삭제 후 퀴즈 번호 자동 정리

5. **최고 점수 보기**
   - 지금까지 기록한 최고 점수 확인

6. **점수 기록 보기**
   - 퀴즈를 푼 날짜와 점수 확인

7. **힌트 기능**
   - 문제 풀이 중 힌트 사용 가능
   - 힌트를 사용한 문제는 정답을 맞혀도 점수 미부여

## 실행 방법

1. 프로젝트 저장소를 복제합니다.

   ```bash
   git clone https://github.com/minhee04/chiikawa-quiz-game.git
   ```

2. 프로젝트 폴더로 이동합니다.

   ```bash
   cd chiikawa-quiz-game
   ```

3. 프로그램을 실행합니다.

   ```bash
   python3 main.py
   ```

## 프로젝트 구조

```text
chiikawa-quiz-game/
├── main.py       # 퀴즈 게임 실행 및 주요 기능
├── state.json    # 퀴즈 데이터와 점수 기록
└── README.md     # 프로젝트 설명
```

## 프로그램 구조

### Quiz 클래스

개별 퀴즈의 문제, 선택지, 정답, 힌트를 관리하고 정답 여부를 확인합니다.

### QuizGame 클래스

퀴즈 추가·조회·삭제, 게임 진행, 점수 관리, JSON 파일 저장 및 불러오기를 담당합니다.

## 데이터 저장

프로그램은 `state.json` 파일을 사용하여 다음 정보를 저장합니다.

- 퀴즈 목록
- 점수 기록
- 최고 점수
